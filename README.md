# Fallen Prince (Падший Принц)

Игра в жанре **Rogue-lite / Survivor Action** (Vampire Survivors-like), созданная в рамках семестрового курса «Проектирование и разработка игровых приложений».

- **Публичная ссылка на игру:** `https://<YOUR_GITHUB_USERNAME>.github.io/<REPO_NAME>/`
- **Стек технологий:** TypeScript, Phaser 4, Vite, GitHub Actions & GitHub Pages.

---

## 1. Что это за игра?

**«Падший Принц»** — динамичный 2D экшен на выживание.
Главный герой — один из сыновей владыки Небесного Царства, решивший отказаться от бессмертия и сбежать на Землю, чтобы прожить смертную жизнь, где каждый прожитый день имеет истинную ценность. Небесные Стражи и летающие Разведчики бросаются в погоню, чтобы силой вернуть беглеца назад.

---

## 2. Как управлять?

| Действие | Клавиши / Мышь |
|---|---|
| **Движение в любую сторону** | `W`, `A`, `S`, `D` или `Стрелки` |
| **Дополнительный ручной удар** | `ПРОБЕЛ`, `Z` или `Левый клик мыши` |
| **Божественный блок (-70% урона)** | `X` или `Shift` (удерживать) |
| **Выбор дара при Level Up** | Цифры `1`, `2`, `3` или `Клик по карточке` |
| **Начать заново (Game Over)** | `ПРОБЕЛ` или `Клик мыши` |

---

## 3. Что должен делать игрок?

1. **Бесконечно перемещаться по святилищу:** Карта бесконечна во всех направлениях — маневрируйте и уводите за собой орду преследователей.
2. **Уничтожать волны врагов:** Автоматическая атака клинком поражает ближайших врагов. Также доступен ручной удар и блок для парирования атак командиров.
3. **Собирать осколки света (кристаллы опыта):** Выпадающие из поверженных врагов кристаллы притягиваются магнитом и заполняют верхнюю шкалу XP.
4. **Выбирать божественные дары (Level Up):** При повышении уровня игра встаёт на паузу, предлагая 1 из 3 улучшений:
   - 🗡 **Священный Меч:** увеличение урона, дальности и скорости авто-атаки.
   - 🔮 **Орбитальные Сферы:** защитные сферы вокруг героя, сбивающие врагов при столкновении.
   - ⚡ **Аура Света:** постоянное сияющее кольцо, непрерывно наносящее урон врагам в радиусе.
   - 🌩 **Кара Небес:** сокрушительные удары молний по врагам.
   - 👟 **Крылья Свободы:** постоянный бонус к скорости передвижения.
   - 💖 **Сердце Смертного:** прибавка к максимальному здоровью и постоянная регенерация.
   - 🧲 **Магнит Света:** значительное увеличение радиуса сбора кристаллов.
5. **Выжить 60 секунд в каждом зале:** Плотность волн непрерывно нарастает. По истечении таймера все оставшиеся враги испаряются в опыт, а игрок исцеляется и переходит в следующий зал. Пройдите 3 зала, чтобы вырваться на Землю!

---

## 4. Что пока НЕ реализовано?

- Финальные боссы с уникальными фазами в конце каждого зала.
- Мета-прогрессия между забегами (постоянные улучшения характеристик за собранные кристаллы).
- Звуковые эффекты ударов, шагов и фоновая музыка.
- Дополнительные персонажи с альтернативным стартовым оружием.
